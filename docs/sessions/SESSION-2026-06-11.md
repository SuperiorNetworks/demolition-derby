## 1. Domino Visualizer Demo & Pivot Decision

Dwain and David demonstrated the domino visualizer tool currently hosted at [https://icssolution.net/Sandstorm/Simulator/](https://icssolution.net/Sandstorm/Simulator/). After reviewing the tool in action, David determined that the physics and dynamics of the domino simulation were not accurate enough to be useful for production planning purposes.

**Decision:** David will pivot the visualizer tool away from domino physics simulation and redirect development effort toward a **Show Planner Tool**. The show planner will allow operators to design, sequence, and preview a full pyrotechnics show before deploying it to the live Sandstorm system. This is a higher-value deliverable that directly supports the production workflow.

A GitHub Issue has been filed to track this pivot — see [Issue #10](https://github.com/SuperiorNetworks/detonator/issues/10).

## 2. Sandstorm Sequence Control — Alpha Demo (v6.11.26)

David demonstrated the latest alpha build of the Sandstorm Sequence Control system. This version represents a significant safety and operational milestone.

### New Features Confirmed in This Build

| Feature | Description |
|---------|-------------|
| **Show Director role** | New user role added; the Show Director has authority to configure and approve the show sequence before arming |
| **Fire Operator role** | The designated operator who initiates the live firing sequence; maps to the industry-standard "Pyrotechnic Operator of Record" role |
| **Safety Officer role** | Independent confirmation role; must confirm readiness before the countdown can begin |
| **Multi-role confirmation gate** | All three roles must confirm before the system transitions to the armed/live state — software implementation of the dual-key protocol |
| **Audible countdown** | Text-to-speech or audio cue announces T-minus 20 seconds, T-minus 10 seconds, and T-minus 5 seconds aloud during the pre-show countdown sequence |

The multi-role confirmation gate and audible countdown directly address the feature requests documented in [SANDSTORM-FEATURE-SPEC.md](https://github.com/SuperiorNetworks/demolition-derby/blob/main/docs/SANDSTORM-FEATURE-SPEC.md) (Issues #4 and #5).

### Outstanding Items from the Feature Spec

The following items from the original feature spec were not yet present in this build and remain open for future development:

- On-screen countdown display with T-minus flash cards (Issue #3)
- User action log with username tagging (Issue #6)
- Live video feed panel with sensor data overlay (Issue #7)
- Unified editor consistency across Timeline, Trigger Editor, and Relay Monitor (Issue #8)
- Manual override / abort during countdown (Issue #9)
